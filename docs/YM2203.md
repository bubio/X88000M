# Yamaha YM2203 Technical Reference

## 概要

Yamaha **YM2203**（通称 *OPN* = FM Operator Type‑N）は、1980年代に登場した6チャンネルのサウンドICです。FM方式による3つの音声チャンネルと、Yamaha YM2149F互換の3チャンネルPSG（矩形波／ノイズ発生器）を統合しています。Wikipediaによれば、このICは12の演算ユニット（オペレータ）を持ち、3チャンネルの各チャンネルを4オペレータで構成し、オペレータ間の接続方法（アルゴリズム）を8種類から選択できる[^2]。各オペレータは13ビットのサイン波を発生し、ADSRエンベロープで音量を制御します[^2]。出力は外付けDAC（通常はYM3014）によりアナログ変換されます[^2]。PSGモジュールは3つの矩形波＋ノイズチャンネルと2つの汎用8ビットI/Oポートを持ち、General InstrumentのAY‑3‑8910/8912と互換です[^1]。

### 特徴

データシートに記載されている主な特徴は次のとおりです[^1][^2]。

- **3チャンネルのFM音源**：各チャンネルは4オペレータ構成。第3チャンネルは各オペレータの周波数を独立に設定できるため、通常の整数比ではない不協和倍音も生成可能[^2]。
- **3チャンネルの矩形波（SSG）＋白色ノイズ**：Yamaha YM2149Fの機能を内蔵し、AY‑3‑8910/8912ソフトウェアと互換[^1]。
- **2系統のプログラマブルタイマ**：タイマAとタイマBを搭載し、サウンド処理や割り込み生成に用いる[^1]。
- **8ビット汎用I/Oポート×2**：SSG部にあり、Z80などのマイクロプロセッサと直接接続できる[^1]。
- **内蔵クロック分周器**：入力クロックの分周比をレジスタで設定でき、FM部とPSG部でそれぞれ異なる分周数を指定する[^3]。
- **TTL互換入出力・単一5 V電源動作**：入力はTTLレベル互換で、5 V単電源で動作[^1]。電源電圧は4.75 V〜5.25 Vの範囲で規定され、入力高レベルは2.0 V以上、入力低レベルは0.8 V以下とされている[^3]。

### 内部構成

YM2203は、**FM音源ブロック**と**SSG（音源＋I/O）ブロック**を共有する**レジスタアレイ**、2つの**プログラマブルタイマ**、およびI/O制御回路から構成されます。FM音源ブロックではオペレータの出力を加算またはフィードバックすることで複数の調波成分を生成します。データシートではFM変調の数学的表現を示し、ベッセル関数を用いた周波数変調式を紹介している[^3]。第3チャンネルは特別モードを持ち、4オペレータそれぞれの周波数を独立設定できる点が他チャンネルと異なります。SSGブロックは、3つの矩形波チャンネルとノイズ発生器および2つの8ビットI/Oポートを持ち、音程生成や音量制御、エンベロープ生成を行います。

## レジスタ・マップ

OPNはCPUからのデータバスを介して2段階アクセス（アドレス指定→データ書き込み）を行います。次表はデータシート[^3]から整理した主要なレジスタ範囲と機能をまとめたものです。長文説明は本文で解説し、テーブルには簡潔なキーワードだけを掲載します。

| レジスタ範囲（16進） | 主な機能（概要） |
|---|---|
| $00 – $05 | PSG矩形波の周波数設定[^3] |
| $06 | ノイズ周波数設定[^3] |
| $07 | 入出力ポート制御／PSGとノイズ出力のON/OFF[^3] |
| $08 – $0A | PSG各チャンネルの音量設定。固定音量かエンベロープ適用を選択[^3] |
| $0B – $0C | PSGエンベロープの周期設定[^3] |
| $0D | PSGエンベロープ形状指定（アタックやリピートなど）[^3] |
| $0E – $0F | 8ビット汎用I/Oポート[^3] |
| $21 | テストレジスタ（常に0に設定）[^3] |
| $24 – $26 | タイマA/Bの設定値（$24と$25でタイマAの上位・下位、$26でタイマB）[^3] |
| $27 | タイマ制御＋第3チャンネルモード設定（各タイマのリセット・有効化・ロード、および3ch独立モード切替）[^3][^3] |
| $2D – $2F | 入力クロック分周比指定（FM部：2〜6、PSG部：1〜4）[^3] |
| $30 – $3E | FM演算のデチューン値・オペレータごとの倍数設定（音色の基本周波数と倍音の関係を決定）[^3] |
| $40 – $4E | 各オペレータのトータル・レベル（変調指数）[^3] |
| $50 – $5E | キー・スケールとアタックレート[^3] |
| $60 – $6E | ディケイレート[^3] |
| $70 – $7E | サステインレート[^3] |
| $80 – $8E | サステインレベルとリリースレート[^3] |
| $90 – $9E | エンベロープ・ジェネレータの特殊パターン[^3] |
| $A0 – $A6 | 各FMチャンネルのキーコード（F‑number）[^3] |
| $A8 – $AE | 第3チャンネル特別モード時のキーコード[^3] |
| $B0 – $B2 | FMアルゴリズムおよびフィードバック設定（モジュレーション接続・自己帰還量）[^3] |
| $B4 – $B6 | スロットごとのキーON/OFF制御（各オペレータの発音開始）[^3] |

### タイマとモードレジスタ

タイマAおよびBはそれぞれ10ビットと8ビットのカウンタで、24H・25H・26Hに設定値を書き込んだ後、27Hのモードレジスタでロードおよび有効化を行う。27Hの各ビットは下記の意味を持ちます[^3]。

- **D7 (RESET B)** – タイマBをリセット（1でリセット、0で動作）。
- **D6 (RESET A)** – タイマAをリセット。
- **D5 (ENABLE B)** – タイマBカウント有効。
- **D4 (ENABLE A)** – タイマAカウント有効。
- **D3 (LOAD B)** – タイマBに設定値をロード。
- **D2 (LOAD A)** – タイマAに設定値をロード。
- **D1–D0** – 第3FMチャンネルのモード。`00`で標準（4オペレータ）、`01`〜`11`で第3チャンネルのオペレータを独立周波数モードにする。

タイマオーバーフロー時にはステータスフラグが立ち、CPUはステータスレジスタをポーリングして割り込み処理を行う。レジスタ0E/0FのI/Oポートは割り込み入力などにも利用できる[^3]。

### FM音色パラメータ

FM部分では各オペレータごとに以下のパラメータを設定することで音色を構成する。

- **Detune/Multiple ($30–$3E)**：基本周波数に対するわずかな周波数シフト（デチューン）と倍音比（1〜31倍）を設定[^3]。
- **Total Level ($40–$4E)**：オペレータの出力レベル（モジュレーション指数）[^3]。
- **Key Scale & Attack Rate ($50–$5E)**：鍵盤番号によるエンベロープ速度の変化率およびアタック段階の速度[^3]。
- **Decay Rate ($60–$6E)**／**Sustain Rate ($70–$7E)**／**Sustain Level & Release Rate ($80–$8E)**：エンベロープの残りの段階を定義[^3]。
- **Algorithm & Feedback ($B0–$B2)**：4つのオペレータをどのように接続するか（8種類）と自己フィードバック量を設定[^3]。

各チャンネルのキーコード（F‑number）は$A0〜$A2でチャンネル1、$A2〜$A4でチャンネル2、$A4〜$A6でチャンネル3を指定する[^3]。特別モード時は$A8〜$AEを利用し、各オペレータに独立したF‑numberを与える[^3]。

## 電気的仕様

データシートの絶対最大定格・推奨動作条件のうち、エミュレータ作成時に重要な項目を以下にまとめます[^3]。

- **電源電圧 (V<sub>dd</sub>)**：4.75 V min. ～ 5.25 V max.　単一5 V電源で動作[^1]。静電破壊を避けるため±0.3 Vを超える電圧を端子に加えないようにする[^3]。
- **入力高レベル (V<sub>IH</sub>)**：2.0 V min. ～ V<sub>dd</sub> max.（TTL互換）[^3]。
- **入力低レベル (V<sub>IL</sub>)**：–0.3 V min. ～ 0.8 V max.[^3]。
- **動作温度範囲**：0 ℃ ～ 70 ℃[^3]。保存温度範囲は–50 ℃ ～ 125 ℃[^3]。

## エミュレーション上の注意点

- **PSG互換性**：YM2203のPSG部はAY‑3‑8910/8912にソフトウェア互換であるため、多くの既存PSGエミュレーションコードを利用できる[^1]。ただし、8ビットI/Oポートが2系統ある点に留意する。
- **タイマ処理**：タイマA/Bのオーバーフローはステータスレジスタ内のFLAG A/Bビットで検出できる。CPU側でタイマ周期に応じてポーリングまたは割り込み処理を行う必要がある。
- **3チャンネル特殊モード**：モードレジスタの下位2ビットで第3FMチャンネルを独立周波数モードに切り替える。各オペレータのF‑number/ブロックは$A8〜$AEで別途設定する[^3]。
- **クロック分周**：FM部とPSG部で動作周波数が異なる。分周比レジスタ($2D～$2F)で設定し、PSG部は1～4、FM部は2～6が有効範囲[^3]。
- **出力**：YM2203自体はデジタル値を出力しない。アナログ出力端子（CHA, CHB, CHC）は外付けのDAC YM3014に接続する。PSG出力とFM出力はミキサ内で合成される。ノイズ発生器は矩形波チャンネルと独立したホワイトノイズを生成し、$06と$07で周波数・ON/OFFを制御する[^3]。

## まとめ

YM2203は3チャンネルFM＋3チャンネルSSG＋ノイズ発生器を備えた低コストの音源ICです。4オペレータ構成による多彩なアルゴリズム、独立周波数設定可能な第3チャンネル、2つの汎用タイマおよびI/Oポートにより、単体でも高機能なサウンドエンジンとして機能します。エミュレータを実装する際は、PSG互換性・レジスタマップ・タイマ処理・クロック分周および3チャンネルの特殊モードを正しく理解し、外付けDACとの接続まで含めて設計する必要があります。本レポートは著作権を侵害しない範囲で技術仕様をまとめたものなので、詳細な信号波形や回路図が必要な場合はオリジナルのデータシートを参照してください。
