# Yamaha YM2203 Technical Reference

## 概要

Yamaha **YM2203**（通称 *OPN* = FM Operator Type‑N）は、1980年代に登場した6チャンネルのサウンドICです。FM方式による3つの音声チャンネルと、Yamaha YM2149F互換の3チャンネルPSG（矩形波／ノイズ発生器）を統合しています。Wikipediaによれば、このICは12の演算ユニット（オペレータ）を持ち、3チャンネルの各チャンネルを4オペレータで構成し、オペレータ間の接続方法（アルゴリズム）を8種類から選択できる[^2]。各オペレータは13ビットのサイン波を発生し、ADSRエンベロープで音量を制御します[^2]。出力は外付けDAC（通常はYM3014）によりアナログ変換されます[^2]。PSGモジュールは3つの矩形波＋ノイズチャンネルと2つの汎用8ビットI/Oポートを持ち、General InstrumentのAY‑3‑8910/8912と互換です[^1]。

### 特徴

データシートに記載されている主な特徴は次のとおりです[^1][^2]。

- **3チャンネルのFM音源**：各チャンネルは4オペレータ構成。第3チャンネルは各オペレータの周波数を独立に設定できるため、通常の整数比ではない不協和倍音も生成可能[^2]。
- **3チャンネルの矩形波（SSG）＋白色ノイズ**：Yamaha YM2149Fの機能を内蔵し、AY‑3‑8910/8912ソフトウェアと互換[^1]。
- **2系統のプログラマブルタイマ**：タイマAとタイマBを搭載し、サウンド処理や割り込み生成に用いる[^1]。
- **8ビット汎用I/Oポート×2**：SSG部にあり、Z80などのマイクロプロセッサと直接接続できる[^1]。
- **内蔵クロック分周器**：入力クロックの分周比をレジスタで設定でき、FM部とPSG部でそれぞれ異なる分周数を指定する[^3]。
- **TTL互換入出力・単一5 V電源動作**：入力はTTLレベル互換で、5 V単電源で動作[^1]。電源電圧は4.75 V〜5.25 Vの範囲で規定され、入力高レベルは2.0 V以上、入力低レベルは0.8 V以下とされている[^3]。

### 内部構成

YM2203は、**FM音源ブロック**と**SSG（音源＋I/O）ブロック**を共有する**レジスタアレイ**、2つの**プログラマブルタイマ**、およびI/O制御回路から構成されます。FM音源ブロックではオペレータの出力を加算またはフィードバックすることで複数の調波成分を生成します。データシートではFM変調の数学的表現を示し、ベッセル関数を用いた周波数変調式を紹介している[^3]。第3チャンネルは特別モードを持ち、4オペレータそれぞれの周波数を独立設定できる点が他チャンネルと異なります。SSGブロックは、3つの矩形波チャンネルとノイズ発生器および2つの8ビットI/Oポートを持ち、音程生成や音量制御、エンベロープ生成を行います。

## レジスタ・マップ

OPNはCPUからのデータバスを介して2段階アクセス（アドレス指定→データ書き込み）を行います。次表はデータシート[^3]から整理した主要なレジスタ範囲と機能をまとめたものです。長文説明は本文で解説し、テーブルには簡潔なキーワードだけを掲載します。

### タイマとモードレジスタ

タイマAおよびBはそれぞれ10ビットと8ビットのカウンタで、24H・25H・26Hに設定値を書き込んだ後、27Hのモードレジスタでロードおよび有効化を行う。27Hの各ビットは下記の意味を持ちます[^3]。

- **D7 (RESET B)** – タイマBをリセット（1でリセット、0で動作）。
- **D6 (RESET A)** – タイマAをリセット。
- **D5 (ENABLE B)** – タイマBカウント有効。
- **D4 (ENABLE A)** – タイマAカウント有効。
- **D3 (LOAD B)** – タイマBに設定値をロード。
- **D2 (LOAD A)** – タイマAに設定値をロード。
- **D1–D0** – 第3FMチャンネルのモード。`00`で標準（4オペレータ）、`01`〜`11`で第3チャンネルのオペレータを独立周波数モードにする。

タイマオーバーフロー時にはステータスフラグが立ち、CPUはステータスレジスタをポーリングして割り込み処理を行う。レジスタ0E/0FのI/Oポートは割り込み入力などにも利用できる[^3]。

### FM音色パラメータ

FM部分では各オペレータごとに以下のパラメータを設定することで音色を構成する。

- **Detune/Multiple ($30–$3E)**：基本周波数に対するわずかな周波数シフト（デチューン）と倍音比（1〜31倍）を設定[^3]。
- **Total Level ($40–$4E)**：オペレータの出力レベル（モジュレーション指数）[^3]。
- **Key Scale & Attack Rate ($50–$5E)**：鍵盤番号によるエンベロープ速度の変化率およびアタック段階の速度[^3]。
- **Decay Rate ($60–$6E)**／**Sustain Rate ($70–$7E)**／**Sustain Level & Release Rate ($80–$8E)**：エンベロープの残りの段階を定義[^3]。
- **Algorithm & Feedback ($B0–$B2)**：4つのオペレータをどのように接続するか（8種類）と自己フィードバック量を設定[^3]。

各チャンネルのキーコード（F‑number）は$A0〜$A2でチャンネル1、$A2〜$A4でチャンネル2、$A4〜$A6でチャンネル3を指定する[^3]。特別モード時は$A8〜$AEを利用し、各オペレータに独立したF‑numberを与える[^3]。

## 電気的仕様

データシートの絶対最大定格・推奨動作条件のうち、エミュレータ作成時に重要な項目を以下にまとめます[^3]。

- **電源電圧 (V<sub>dd</sub>)**：4.75 V min. ～ 5.25 V max.　単一5 V電源で動作[^1]。静電破壊を避けるため±0.3 Vを超える電圧を端子に加えないようにする[^3]。
- **入力高レベル (V<sub>IH</sub>)**：2.0 V min. ～ V<sub>dd</sub> max.（TTL互換）[^3]。
- **入力低レベル (V<sub>IL</sub>)**：–0.3 V min. ～ 0.8 V max.[^3]。
- **動作温度範囲**：0 ℃ ～ 70 ℃[^3]。保存温度範囲は–50 ℃ ～ 125 ℃[^3]。

## エミュレーション上の注意点

- **PSG互換性**：YM2203のPSG部はAY‑3‑8910/8912にソフトウェア互換であるため、多くの既存PSGエミュレーションコードを利用できる[^1]。ただし、8ビットI/Oポートが2系統ある点に留意する。
- **タイマ処理**：タイマA/Bのオーバーフローはステータスレジスタ内のFLAG A/Bビットで検出できる。CPU側でタイマ周期に応じてポーリングまたは割り込み処理を行う必要がある。
- **3チャンネル特殊モード**：モードレジスタの下位2ビットで第3FMチャンネルを独立周波数モードに切り替える。各オペレータのF‑number/ブロックは$A8〜$AEで別途設定する[^3]。
- **クロック分周**：FM部とPSG部で動作周波数が異なる。分周比レジスタ($2D～$2F)で設定し、PSG部は1～4、FM部は2～6が有効範囲[^3]。
- **出力**：YM2203自体はデジタル値を出力しない。アナログ出力端子（CHA, CHB, CHC）は外付けのDAC YM3014に接続する。PSG出力とFM出力はミキサ内で合成される。ノイズ発生器は矩形波チャンネルと独立したホワイトノイズを生成し、$06と$07で周波数・ON/OFFを制御する[^3]。

# 実装ガイド (本リポジトリでの加筆)

ここから先のセクションは、X88000M の Phase C で **YM2203 をスクラッチ実装するために必要な技術情報** を、公知の YM2203 仕様に基づいてまとめたものです。本リポジトリのライセンス汚染を避けるため、**ymfm / fmgen / MAME 等の他プロジェクトのソースコードや解説テキストは一切参照していません**。すべて公開仕様 (Yamaha データシート / 公知のレジスタマップ) を元にした自作の解説です。

## FM レジスタのビット詳細

各 FM パラメータは「スロット (= オペレータ) ごと」または「チャンネルごと」に配置されています。以下のビット配置は YM2203 / OPN 系 FM 音源の標準的な仕様です。

| アドレス | bit7 | bit6 | bit5 | bit4 | bit3 | bit2 | bit1 | bit0 | 意味 |
|---|---|---|---|---|---|---|---|---|---|
| `$30`–`$3E` | – | DT2 | DT1 | DT0 | MUL3 | MUL2 | MUL1 | MUL0 | DT (3bit) + MULTIPLE (4bit) |
| `$40`–`$4E` | – | TL6 | TL5 | TL4 | TL3 | TL2 | TL1 | TL0 | TOTAL LEVEL (7bit、0=最大、127=無音) |
| `$50`–`$5E` | KS1 | KS0 | – | AR4 | AR3 | AR2 | AR1 | AR0 | KEY SCALE (2bit) + ATTACK RATE (5bit) |

### グローバル

| アドレス | 意味 |
|---|---|
| `$22` | LFO 制御 (YM2203 は LFO 無し → 無視) |
| `$28` | キー ON/OFF: bit7..bit4 = OP4/OP3/OP2/OP1 のキーマスク, bit2..bit0 = チャンネル番号 (0/1/2 のみ有効) |

### `$28` (Key On/Off) ビット詳細

```
 7   6   5   4   3   2   1   0
[OP4][OP3][OP2][OP1][ - ][CH2][CH1][CH0]
```

- `OP1`–`OP4`: そのオペレータをキーオン (1) するかキーオフ (0) するか
- `CH0`–`CH2`: 対象 FM チャンネル (0..2)。3 以上は YM2203 では無効
- 1回のレジスタ書き込みで指定チャンネルの 4 オペレータすべての キー状態を一括更新する

## オペレータのスロット順序 (1, 3, 2, 4 の罠)

`$30`–`$9E` の各レジスタは「16スロット (4チャンネル × 4オペレータ)」をリニアに並べた配置になっていますが、**スロット番号と オペレータ番号は素直な順番ではありません**。これは YAMAHA FM 音源全般に共通する有名な仕様で、エミュレータ実装で最も間違えやすい点です。

| アドレス下位 | オペレータの実体 |
|---|---|
| `$x0` | CH1 OP1 |
| `$x1` | CH2 OP1 |
| `$x2` | CH3 OP1 |
| `$x3` | (未使用 — OPNA では CH4 OP1) |
| `$x4` | **CH1 OP3** ← OP2 ではない |
| `$x5` | **CH2 OP3** |
| `$x6` | **CH3 OP3** |
| `$x7` | (未使用) |
| `$x8` | **CH1 OP2** ← OP3 ではない |
| `$x9` | **CH2 OP2** |
| `$xA` | **CH3 OP2** |
| `$xB` | (未使用) |
| `$xC` | CH1 OP4 |
| `$xD` | CH2 OP4 |
| `$xE` | CH3 OP4 |
| `$xF` | (未使用) |

**実装メモ**: レジスタ書き込みハンドラは `(reg & 0x03)` でチャンネル, `(reg >> 2) & 0x03` でスロットインデックスを取り、スロットインデックス `0,1,2,3` を **オペレータ番号 `1,3,2,4`** に変換するルックアップテーブルを必ず用意すること。

## F-Number と位相増分

YM2203 の各オペレータは 11-bit の **F-Number** と 3-bit の **BLOCK** で発音周波数が決まります。BLOCK は MIDI でいうオクターブ番号、F-Number はオクターブ内の音高です。

```
phase_increment_per_FM_clock = (F_Number << BLOCK) >> 1   ; 単位は 1/(2^20) 周期
```

つまり位相累算器を 20bit (もしくはそれ以上) で持ち、上位 10bit を sin テーブルのインデックスに使います (一般的な実装では位相テーブル 1024 × エンベロープ振幅と組み合わせる)。

連続周波数として表すと:

```
f_out [Hz] = master_clock / (PRESCALER * 6 * 24)   * (F_Number / 2^20) * 2^BLOCK
```

PC-8801 で使われる典型的な値は:

- `master_clock` = 3.9936 MHz (3.5795 MHz の場合もある — モデル依存)
- `PRESCALER` = `$2D` 系で設定 (FM 部のプリスケーラは 6 がデフォルト)

つまり 1 FM クロックあたりおよそ `3993600 / 6 / 24 ≈ 27733 Hz` でオペレータが回ります。サウンド出力サンプリング (44.1 kHz) に変換するには、フラクショナル累積器 (位相累積器とは別) で「FM 1サンプルを何個分の出力サンプルに引き伸ばすか」を管理します。

## エンベロープ・ジェネレータの段階

各オペレータは独立した 4 段エンベロープを持ちます。

```
KeyOn ─→ Attack(AR) ─→ Decay(DR) ─→ Sustain(SR) ─→ KeyOff ─→ Release(RR)
                                  ↑
                                  SL に達した時点で DR→SR に遷移
```

- **AR (Attack Rate, 5bit)**: エンベロープを最大値に近づける速度。AR の特性は **指数関数的** ではなく **指数を1から引いた形** (`1 - exp(-t)`) で実装されるのが一般的
- **DR (Decay Rate, 5bit)**: AR で最大に達したあと、SL まで線形に減衰させる速度
- **SL (Sustain Level, 4bit)**: DR から SR への遷移点 (0=ほぼ最大、15=ほぼゼロ)
- **SR (Sustain Rate, 5bit)**: SL 到達後、ノートが続いている間も減衰し続ける速度
- **RR (Release Rate, 4bit)**: KeyOff された後の減衰速度 (4bit なので実効5bit値は `RR<<1 | 1`)
- **KS (Key Scale, 2bit)**: 高音ほどエンベロープを速くする補正 (= **KSR**)。最終的なレートは:
  ```
  effective_rate = 2 * RATE + KSR    (0..63 にクランプ)
  KSR = (BLOCK << 1 | (F_Number >> 10)) >> (3 - KS)   ; KS=0 で最大シフト
  ```
- **TL (Total Level, 7bit)**: エンベロープ出力に常時加算される減衰量 (0=減衰なし、127=実質ゼロ)。`0.75 dB / step` 換算

エンベロープ値そのものは `0..1023` の **減衰量** (大きいほど無音に近い) として保持し、最終的に op 出力 = `sin_table[phase] + envelope` で対数領域で和を取り、`exp_table` で線形に戻すのが標準的な実装です。

## アルゴリズム (オペレータ接続の8パターン)

`$B0`–`$B2` の下位 3bit (ALGO 0..7) で、4 オペレータの接続トポロジを選びます。`OPx → OPy` は「OPx の出力を OPy の位相変調入力に加える」という意味です。出力 (キャリア) は ☆ で示します。

| ALGO | 接続 | 用途 |
|---|---|---|
| 0 | OP1→OP2→OP3→OP4☆ | 直列 4-op (シリアル接続。最も明るい音色) |
| 1 | (OP1+OP2)→OP3→OP4☆ | 並列モジュレータ → 直列 |
| 2 | OP1→(OP2+OP3)→OP4☆... | 厳密には OP2 と OP3 の出力を OP4 の入力に和算 |
| 3 | OP1→OP2 + OP3→OP4☆ | 2-op の組を 2 段直列 |
| 4 | (OP1→OP2☆) + (OP3→OP4☆) | 2-op を 2 系統並列 |
| 5 | OP1→{OP2☆, OP3☆, OP4☆} | 1 モジュレータ + 3 キャリア |
| 6 | OP1→OP2☆ + OP3☆ + OP4☆ | 1 直列ペア + 2 単独キャリア |
| 7 | OP1☆ + OP2☆ + OP3☆ + OP4☆ | 4 オペレータ全員がキャリア (PSG 的な加算合成) |

**フィードバック**: `$B0`–`$B2` の bit5–3 (FB, 3bit) は **OP1 のみ** に適用される自己フィードバック量です。OP1 の最新出力サンプルと 1 サンプル前の出力サンプルを平均し、それを OP1 の位相変調入力に加える、という形式が一般的です。FB=0 で無効、FB=7 で最大。

## SSG 部 (PSG) の実装メモ

YM2203 の SSG 部は **AY-3-8910 / YM2149 と完全互換** です。

### レジスタ詳細

| アドレス | 内容 |
|---|---|
| `$00`/`$01` | CH A トーン周期 (12bit、`$00`=下位 8bit, `$01`=上位 4bit) |
| `$02`/`$03` | CH B トーン周期 |
| `$04`/`$05` | CH C トーン周期 |
| `$06` | ノイズ周期 (5bit) |
| `$07` | ミキサ: bit0..2 = トーン enable (0=有効), bit3..5 = ノイズ enable (0=有効), bit6/7 = I/O port 方向 |
| `$08`/`$09`/`$0A` | CH A/B/C 振幅: bit0..3 = 振幅 (4bit log), bit4 = エンベロープ使用フラグ |
| `$0B`/`$0C` | エンベロープ周期 (16bit) |
| `$0D` | エンベロープ形状 (4bit, 下記参照) |
| `$0E`/`$0F` | I/O ポート A/B (8bit、PC-8801 ではジョイスティックとカレンダーに使う) |

### トーン生成

各チャンネルのトーン周期 N に対して、出力周波数は `f = SSG_clock / (16 * N)`。

PC-8801 における SSG クロックはプリスケーラの設定に依存しますが、典型的には `master_clock / 4 = ~1.0 MHz`。

### ノイズ生成

17-bit LFSR で実装します:

```
bit_out = LFSR & 1
new_bit = ((LFSR >> 0) ^ (LFSR >> 3)) & 1   ; XOR feedback at taps 0, 3
LFSR = (LFSR >> 1) | (new_bit << 16)
```

LFSR 進行のレートは `f_noise = SSG_clock / (16 * NoisePeriod)` (N=0 のときは 1 として扱う)。

### 4-bit ボリューム → 線形振幅テーブル

SSG の振幅は 4-bit log。**約 1.5 dB / step** で、`0` がゼロ、`15` が最大。線形値は次のように**自前で計算**します:

```c
// vol[0] = 0
// vol[i] = vol[i-1] * 10^(1.5/20)   for i = 1..15
// あるいは: vol[i] = 32767 * pow(10.0, (i - 15) * 1.5 / 20)
```

(具体的な定数表は他者のコードからコピーせず、上記の式から `Initialize()` 内で生成すること)

### エンベロープ形状

`$0D` の下位 4bit `[CONT][ATTACK][ALTERNATE][HOLD]` の組み合わせで 8 種類のパターンが選べます (上位 4 通りは下位 4 通りと同じ動きをします)。

| 形状値 | 動作 |
|---|---|
| `0..3` (CONT=0) | 1回だけ下降 (`\___`) |
| `4..7` (CONT=0, ATT=1) | 1回だけ上昇後ゼロ (`/___`) |
| `8`  (`\\\\`) | 鋸歯下降を繰り返す |
| `9`  (`\___`) | 1回下降してホールド (= 0..3 と同じ) |
| `10` (`\/\/`) | 下降→上昇を繰り返す |
| `11` (`\¯¯¯`) | 下降してから最大値ホールド |
| `12` (`////`) | 鋸歯上昇を繰り返す |
| `13` (`/¯¯¯`) | 上昇してから最大値ホールド |
| `14` (`/\/\`) | 上昇→下降を繰り返す |
| `15` (`/___`) | 上昇してから 0 にホールド (= 4..7 と同じ) |

## CH3 特殊モード

`$27` のビット 6/7 で CH3 を「特殊モード」にすると、CH3 の 4 オペレータそれぞれに**異なる F-Number / BLOCK** を与えられるようになります。これにより不協和な倍音や非整数比の音色を作ることができます。

- 通常モード: CH3 の全 4 オペレータは `$A2` (低位) / `$A6` (高位) で同じ F-Number を共有
- 特殊モード:
  - OP4 → `$A2` / `$A6` (通常の場所)
  - OP1 → `$A8` / `$AC`
  - OP2 → `$A9` / `$AD`
  - OP3 → `$AA` / `$AE`

## PC-8801 における YM2203

- **接続 I/O ポート**: `$44` (アドレス / ステータス読み出し), `$45` (データ書き込み / 読み出し)
- **マスタクロック**: 約 3.9936 MHz (機種により若干異なる)
- **割り込み**: タイマ A/B のオーバーフローをステータスレジスタで読み取り、Z80 INT に接続
- **ステレオ**: YM2203 はモノラル出力のため、SDL3 ステレオストリームへ流す際は L/R に同じサンプルを書く

## ステータスレジスタ

`$44` を読み出すと取得できる 8bit:

| bit | 意味 |
|---|---|
| 7 | BUSY (書き込み直後の少しの間 1) |
| 6..2 | 0 (未使用) |
| 1 | TIMER B オーバーフロー (1 で発生中、`$27` の RESET B でクリア) |
| 0 | TIMER A オーバーフロー (1 で発生中、`$27` の RESET A でクリア) |

## ライセンス上の自衛策 (本リポジトリ方針)

X88000 はフリーライセンスで配布されており、他プロジェクトのコードによる汚染は厳禁です。Phase C の実装にあたっては:

1. **既存の FM 音源コード (ymfm / fmgen / MAME / Game_Music_Emu / 等) は一切参照しない**。アルゴリズムを思い出すために眺めることもしない
2. **定数テーブルもコピーしない**。sin / exp / エンベロープレート / DT 値などはすべて `Initialize()` 内の数式から導出する
3. 仕様 (レジスタアドレス、ビット配置、計算式) は **事実情報** であり著作権の対象外。本ドキュメントの式や表をコメントとしてソースに引用することは問題なし
4. 他者の解説テキスト (Wikipedia 等) の **逐語訳** はしない。本ドキュメントに書かれた解説はオリジナルの言い回しで書くこと
5. 分からない箇所は「データシートを見る」「自分で実験する」で対応し、安易に他コードを覗かない

これに準拠することで、X88000M 全体のフリーライセンス互換性を維持します。

## まとめ

YM2203は3チャンネルFM＋3チャンネルSSG＋ノイズ発生器を備えた低コストの音源ICです。4オペレータ構成による多彩なアルゴリズム、独立周波数設定可能な第3チャンネル、2つの汎用タイマおよびI/Oポートにより、単体でも高機能なサウンドエンジンとして機能します。エミュレータを実装する際は、PSG互換性・レジスタマップ・タイマ処理・クロック分周および3チャンネルの特殊モードを正しく理解し、外付けDACとの接続まで含めて設計する必要があります。本レポートは著作権を侵害しない範囲で技術仕様をまとめたものなので、詳細な信号波形や回路図が必要な場合はオリジナルのデータシートを参照してください。
